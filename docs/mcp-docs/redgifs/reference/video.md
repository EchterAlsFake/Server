# Video — RedGIFs API

`Video(url=..., core=...)` is a keyword-only `BaseMedia` dataclass. Prefer
`await client.get_video(...)`. Construction normalizes identity without fetching;
loaders return mappings committed atomically through the shared media contract.

## Fields

| Field | Type | Source | Meaning |
| --- | --- | --- | --- |
| `url` | `str` | identity | Canonical www watch URL, or canonical profile/niche/collection URL. |
| `core` | `BaseCore` | identity | Shared caller-configurable backend; omitted from to_dict() by default. |
| `video_id` | `str` | identity | Stable lowercase media ID; retained on Image for interface compatibility. |
| `title` | `str \| None` | html | HTML display title generated by the site; API-only access leaves this unloaded. |
| `page_description` | `str \| None` | html | HTML page description, kept even after API description takes precedence. |
| `html_content_url` | `str \| None` | html | Content URL from the matching HTML structured object; video HTML may point to silent media. |
| `html_publish_date` | `str \| None` | html | Original HTML date string; currently malformed, not a normalized date. |
| `html_metadata` | `dict \| None` | html | Matching SocialMediaPosting JSON-LD, including the target VideoObject/ImageObject. |
| `description` | `str \| None` | api, html | API description when API is loaded, even when null/empty; otherwise HTML description. |
| `thumbnail_url` | `str \| None` | api, html | Thumbnail/profile image URL supplied by the selected source. |
| `embed_url` | `str \| None` | api, html | Embed URL from API, or HTML when API has not loaded. |
| `duration` | `float \| None` | api | Duration in seconds; null on images. |
| `length` | `str \| None` | api | Duration seconds as text; null if absent. |
| `publish_date` | `str \| None` | api | UTC ISO 8601 string normalized from API Unix seconds. |
| `views` | `int \| None` | api | Site-reported integer view count. |
| `likes` | `int \| None` | api | Site-reported integer like count. |
| `tags` | `list[str] \| None` | api | Site tag names; preserve returned spelling. |
| `width` | `int \| None` | api | API-reported original width in pixels. |
| `height` | `int \| None` | api | API-reported original height in pixels. |
| `has_audio` | `bool \| None` | api | Site-reported flag, not a container probe; known inaccurate legacy values are preserved. |
| `verified` | `bool \| None` | api | Site-reported uploader/profile verification flag. |
| `published` | `bool \| None` | api | Site-reported publication flag. |
| `author` | `str \| None` | api | Uploader username. |
| `author_link` | `str \| None` | api | Canonical uploader /users/ URL; use get_author() for a typed User. |
| `poster_url` | `str \| None` | api | Poster image URL. |
| `preview_video_url` | `str \| None` | api | Optional vthumbnail clip; may appear only on listing cards. |
| `timeline_url` | `str \| None` | api | Optional timeline image URL; may be absent from detail responses. |
| `content_url` | `str \| None` | api | HD direct media URL, falling back to SD if HD is absent. |
| `sources` | `dict[str, str] \| None` | api | Actual hd/sd/silent rendition labels mapped to exact URLs, including signed queries. |
| `available_qualities` | `list[str] \| None` | api | Available rendition labels; use get_qualities() for a copied list. |
| `niche_ids` | `list[str] \| None` | api | Related niche IDs; use get_niches() for typed details. |
| `sexuality` | `list[str] \| None` | api | Site classification strings. |
| `content_type` | `str \| None` | api | Site content classification, when supplied. |
| `average_color` | `str \| None` | api | Site-provided average color string. |
| `gallery_id` | `str \| None` | api | Optional image gallery membership ID; enumeration is not implemented. |
| `media_type` | `int \| None` | api | 1 for Video, 2 for Image. |
| `hls_urls` | `dict[str, str] \| None` | api | HD/SD byte-range HLS playlist URLs for inspection; not accepted by download(). |
| `raw_metadata` | `dict \| None` | api | Original matched API record, preserving additional site fields. |

API values take precedence for `description`, `thumbnail_url`, and `embed_url`, including
known `None` values. HTML-only `title`, `page_description`, and raw structured metadata
remain available after both sources load. Zero counts remain zero; absent values are
nullable and unloaded values raise `DataNotLoadedError`.

`has_audio` is a site flag, not a file probe. Legacy `happyfrenchindianspinyloach` reports
false while its direct MP4 contains audible AAC. HTML publication dates are malformed;
use API `publish_date` for normalized UTC dates. Optional card preview/timeline URLs may
be absent from the detail endpoint. No FPS, codec, dislikes or comment count is fabricated.

## Relationships and qualities

```python
async def get_author(*, load_api: bool = True) -> User | None: ...
async def get_niches() -> list[Niche]: ...
async def get_qualities() -> list[str]: ...
async def get_download_url(quality="best", *, refresh: bool = False) -> str: ...
async def download(configuration: DownloadConfigRAW) -> bool: ...
```

`get_author()` loads `author_link` if necessary and returns a typed profile, or `None`
when the source has no author. Missing/deleted profiles retain their loading error.
`get_niches()` loads typed API details for all supplied niche IDs.

`get_qualities()` returns a copied list of `hd`, `sd` and optional `silent` labels.
`get_download_url()` accepts those exact labels plus `best`, `half`, and `worst`.
An absent exact rendition or numeric resolution raises `ValueError`. Refresh requests
fresh public detail metadata for the selected URL without replacing the model's already
committed source snapshot. Downloads always refresh and preserve signed URL queries.

`download()` requires `DownloadConfigRAW`, returns a boolean, and uses the shared raw
downloader. It copies the caller configuration before filename changes. The default
filename uses an already-loaded title, otherwise the stable ID; it does not fetch HTML
just to name a file. With `no_title=True`, `path` is the exact filename. The decorated
download entry point wraps ordinary selection/transport errors in `DownloadFailed` while
preserving their causes and cancellation.

and [shared media](../../eaf-base-api/reference/base-media.md).
