# Supported platforms and hosts — YouJizz API

Requires Python 3.12+. Prior live validation used Linux/Python 3.13 and FFmpeg/ffprobe;
other platforms have not been verified for this provider.
Only youjizz.com and www.youjizz.com are accepted. The apex redirects to www.
Numeric IDs, `/videos/<slug>-<id>.html` and `/videos/embed/<id>` identify videos.
No alternate mirror or language subdomain was confirmed. English/Chinese UI
translation does not imply locale routes. Access challenges and required age
verification fail explicitly.
