YouJizz API getting started

Version 0.1.0. Requires Python 3.12+, eaf-base-api[hls]>=4.2.6 and selectolax.

pip install unofficial-api-for-youjizz
youjizz_api -h

import asyncio
from youjizz_api import Client, DownloadConfigRAW

async def main():
    async with Client() as client:
        video = await client.get_video("48914471", load_api=True, load_html=True)
        print(video.title, video.duration, video.available_qualities)
        await video.download(DownloadConfigRAW(quality="worst", path="./downloads"))

asyncio.run(main())

FFmpeg is required for HLS remuxing; ffprobe is used by live download checks. Client closes its own core, while injected BaseCore instances remain caller-owned. See Client, source loading and downloading.

Downloading — YouJizz API

from youjizz_api import DownloadConfigRAW, DownloadConfigHLS
await video.download(DownloadConfigRAW(quality="worst", path="./downloads"))
await video.download(DownloadConfigHLS(quality="best", path="./downloads", remux=True))

HTML loading supplies direct_urls and hls_urls by numeric encoding label. available_qualities is their sorted union, including labels such as 288 or 368. Downloads use per-quality masters because Auto may omit older renditions. Presets best/half/worst select the highest/middle/lowest sorted label. Missing numeric quality selects the nearest, preferring the higher label on a tie. Signed queries are preserved. Refresh expired URLs with refresh_sources(). For explicit filenames set no_title=True and a complete path. Shared download reports, callbacks and cancellation remain available. Actual dimensions can differ from encoding labels, especially portrait media.

Iteration and results — YouJizz API

pages is a positive page count or "all"; start_page is one based. HTML pagination follows actual Next links, retains filters and detects repeated pages. Public user uploads use the same 24-ID slices as the website UI. IteratorConfig controls item concurrency, loading, errors and original/completion order. HTML discovery is sequential; page concurrency does not prefetch unknown links.

from contextlib import aclosing
from youjizz_api import Client, IteratorConfig

async with Client() as client:
    async with aclosing(client.videos(pages=2, iterator_config=IteratorConfig(order="original"))) as stream:
        async for result in stream:
            video = result.unwrap()
            await video.load_fields("title")
            print(video.video_id, video.title)

Close partially consumed generators with contextlib.aclosing.

Source behavior and metadata variants

The suite checks API-only, HTML-only, combined, both sequential orders, deferred fields, and serialization without incidental fetches. API precedes HTML for shared fields, except thumbnails: legacy video 48914471 returns an empty API thumbnail while HTML has a real image. Empty URLs stay absent rather than resolving to the site root. HTML retains description, calendar publication date, embed/canonical identity, tag names, exact rating/votes, author references, and signed media maps. Preview and sprite metadata come from the thumbnail API. Comments have a separate lazy source; their integer timestamps are Unix seconds.

Representative metadata pages include IDs 30792291 (rich description and ratings), 83968481 (no rating/votes), 48914471 (legacy/288p and empty API thumbnail), and 75799072 (nonstandard 368p). The requested VideoObject and hidden video ID must agree. Sparse video 128889181 has an empty title slug and omits VideoObject JSON-LD; its Open Graph URL and hidden ID must both identify the requested video before ordinary Open Graph fields are accepted. The regression compares its exact duration, thumbnail, publication date, missing title, and stable identity against the live page. A real nonexistent ID 999999999999999 returns HTTP 404 and remains an error.

Private user fields are filtered according to public flags. Contact/internal fields returned by the raw endpoint are not copied into domain objects. Public uploads are governed separately by the UI's public-video flag. Required age verification or access challenges fail explicitly.

Searching and filtering — YouJizz API

Use Client.videos(listing=Listing.POPULAR) for popular/newest/top/week/month, trending and HD listings, and Client.random_videos() for the random page. Enums are in youjizz_api.modules.sorting. Client.search_videos supports relevance/newest/views/rating/length sorting, duration ranges, phrase mode, title_only and date_from/date_to calendar dates. Empty queries raise ValueError. The website disables HD keyword search; use the separate HD listing rather than assuming a search HD filter works.

from youjizz_api.modules.sorting import Sort
stream = client.search_videos("Leah Gotti", pages=2, sort=Sort.VIEWS)

Category/tag listings and the alphabetical pornstar directory are separate APIs; account management, uploads, favorites and playlists are unsupported.

Quickstart

import asyncio
from contextlib import aclosing
from youjizz_api import Client, DownloadConfigRAW, IteratorConfig
from youjizz_api.modules.sorting import Sort

async def main():
    async with Client() as client:
        video = await client.get_video("https://www.youjizz.com/videos/video-48914471.html",
                                       load_api=True, load_html=True)
        print(video.title, video.duration, video.available_qualities)
        await video.download(DownloadConfigRAW(quality="worst", path="./downloads"))
        stream = client.search_videos("Leah Gotti", pages=2, sort=Sort.VIEWS,
                                     iterator_config=IteratorConfig(order="original"))
        async with aclosing(stream):
            async for result in stream:
                item = result.unwrap()
                await item.load_fields("title")
                print(item.video_id, item.title)

asyncio.run(main())

pages is a positive page count or "all"; start_page is one based. HTML pagination follows the site's actual Next links, retains filters, and detects repeated pages. User uploads use the site's public ID list and the same 24-ID page slices as its Angular UI. IteratorConfig retains item concurrency, source/field loading, error modes, and original/completion ordering. HTML pages are discovered sequentially; page concurrency does not prefetch unknown Next links. Listing objects initially contain identity only; opt into detail loading with load_specific_sources or load_specific_fields.

from youjizz_api import Client

async def inspect_sources():
    async with Client() as client:
        video = await client.get_video("30792291", load_api=False, load_html=False)
        print(video.to_dict())            # no network fetch, unloaded fields omitted
        await video.load_sources("api")   # /api/thumbs?ids=30792291
        await video.load_fields("tags")   # HTML only
        await video.load_sources("comments")
        print(video.comment_count)

Synchronous access to an unloaded field raises the shared DataNotLoadedError. None means the loaded source knows the field is absent. Empty-title uploads with an empty URL slug are accepted; pages without VideoObject JSON-LD use Open Graph only when both the hidden ID and the Open Graph URL identify the requested video. API-only, HTML-only, both, and deferred loading are independent; loading either order gives the same precedence.

Source Fields and semantics
API (/api/thumbs) Title, duration (integer seconds), length (display string), views (decimal string), thumbnail, preview URL, HD flag, thumbnail count, sprite URL
HTML (matching VideoObject JSON-LD, identity-checked Open Graph fallback, DOM, public dataEncodings) Title/duration/length/views/thumbnail fallback; description; publish date (site calendar date, no invented timezone); canonical/embed URLs; tags; rating (nullable float out of 5); rating votes (integer); author ID and public author link/name when rendered; direct/HLS maps and available qualities
Comments (/api/comments/{id}) Typed comments (Unix timestamps in seconds), including replies, excluding like/dislike action rows; count is the number of these returned records, not an inferred UI total

API precedes HTML for shared fields except thumbnails: HTML takes precedence because the thumbnail API returns an empty string on some legacy videos. API-only loading reports that absence as None. Rating uses HTML precision; the thumbnail API's rounded score is not substituted. available_qualities is the sorted union of the site's numeric encoding labels; direct_urls and hls_urls give format-specific availability. Labels can include 288, 368, and portrait height 1920. Actual dimensions are checked against completed downloads in the live suite.

m3u8_base_url retains the site's Auto master when present, otherwise a real per-quality master. Downloads select the per-quality master: Auto can omit older renditions. Quality presets are best, half (middle sorted label), and worst; a missing numeric quality uses the nearest label, preferring the higher one on a tie. Signed query strings remain intact. Download configurations are copied without replacing callbacks or cancellation events. await video.refresh_sources() returns a new HTML-loaded Video after refreshing the core cache; use it when source URLs expire.

User profile metadata respects the site's public flags, including hidden usernames. Public upload lists remain available when the site separately marks videos public. Raw profile responses, contact information, internal fields, and private favorites are not exposed. Account management, uploads, favorites, and playlists are outside the supported public interface; the site's playlist feature is disabled and the observed favorites request failed with HTTP 500.

Only youjizz.com and www.youjizz.com are accepted. The apex redirects to www. Numeric video IDs and /videos/embed/{id} links are supported. No alternate mirror or language subdomain was confirmed. The site disables its search-HD feature and the rendered hd=1 search control still returns SD videos; no HD search filter is advertised. Its separate HD listing remains available. The UI offers English and Chinese through client-side translation; this provider does not invent locale-specific routes. Access challenges and required age verification fail explicitly.

Collections and User — YouJizz API

Collection(url=..., core=..., name=..., video_count=None) exposes videos(pages=1, *, start_page=1, iterator_config=None). Pornstar and Category inherit Collection. Directory video counts are snapshots. Pornstar entries point to keyword search; there is no separate biography endpoint. No Model or Channel class is provided.

await client.get_user(url, load_api=True) accepts numeric user IDs or /profile/user/<id> URLs. User fields include name, description, title, avatar_url, date_joined, last_login, is_public, public_videos and banned. user.videos(...) follows numbered upload slices from the public video-ID list. Hidden usernames and public-upload flags are independent and respected. Private profile fields, contact information and favorites are not exposed.

Video — YouJizz API

Video(BaseMedia) has independent api, html and comments sources. API fields: title, duration (integer seconds), length, views (decimal string), thumbnail_url, preview_video_url, is_hd, thumbnail_count and sprite_url. HTML adds description, publish_date (site calendar date), canonical_url, embed_url, tags, rating (float out of 5), rating_votes, author_id, author_name, author_link, direct_urls, hls_urls, m3u8_base_url, available_qualities and content_url. API takes precedence for shared fields except thumbnail_url, which prefers HTML.

await video.get_author(load_api=True) returns User or None. video.related_videos(...) yields related result objects. await video.load_sources("comments") loads typed comments and comment_count. The count covers returned comment records, excluding action rows; reply references and Unix timestamps are preserved. await video.refresh_sources() returns a new HTML-loaded Video with refreshed cache. Unloaded fields raise DataNotLoadedError; loaded absent fields are None.

Errors — YouJizz API

DataNotLoadedError means the required source has not been loaded; use load_fields or load_sources. A loaded None represents absent metadata. Shared MediaLoadError can wrap provider/network errors; inspect its cause. Invalid host/path/query/directory arguments raise validation errors. Refresh expired sources before retrying a download. An empty or unrecognized directory raises ValueError rather than claiming success. HTTP challenges and age verification are surfaced; do not bypass access controls. No browser cookies are read by the live tests.
