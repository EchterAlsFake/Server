📦 Installation

Install the library from PyPI using pip:

bash
pip install unofficial-api-for-tnaflix
Note
Requires Python ≥ 3.12 and eaf-base-api>=4.2.5. The networking engine is installed automatically.

Release 1.0.1 requires eaf-base-api>=4.2.5 from PyPI. A local base-API checkout is not required.

🚀 Quick Start

All operations are asynchronous and should be executed within an async context:

python
import asyncio
from tnaflix_api import Client
from base_api import DownloadConfigRAW

async def main():
    client = Client()

    # Fetch a video
    video = await client.get_video("https://www.tnaflix.com/hd-videos/example-video-12345")

    # Print metadata
    print(f"Title: {video.title}")
    print(f"Duration: {video.length} ({video.duration}s)")
    print(f"Available Qualities: {video.video_qualities}")

    # Download video using progressive MP4 downloader
    config = DownloadConfigRAW(quality="best", path="./downloads")
    success = await video.download(configuration=config)
    print(f"Download complete: {success}")

asyncio.run(main())

⚙️ Configuration

TNAFlix API uses eaf_base_api for networking. Configure proxies, request attempts, timeouts, limits, and headers through a custom BaseCore.

Please refer to the eaf_base_api Documentation for the complete reference on how to set up RuntimeConfig and BaseCore.

python
from base_api import BaseCore
from base_api.modules.config import RuntimeConfig
from tnaflix_api import Client

config = RuntimeConfig()
config.proxy = "socks5://127.0.0.1:9050"
config.request_attempts = 3

core = BaseCore(configuration=config)
client = Client(core=core)

IteratorConfig, retry policy, and custom scrape errors

Iterator methods accept an iterator_config object. By default, the API eagerly loads the html source for extracted media items.

python
from base_api import ErrorAction, ErrorMode, ResultOrder, RetryPolicy, ScrapeErrorContext
from base_api.modules.config import IteratorConfig

async def handle_scrape_error(context: ScrapeErrorContext) -> ErrorAction:
    print(context.stage, context.url, context.error, context.attempt)
    return ErrorAction.RETRY

retry = RetryPolicy(max_attempts=3, base_delay=0.5, multiplier=2, max_delay=8)
iterator_config = IteratorConfig(
    max_page_concurrency=2,
    max_item_concurrency=5,
    order=ResultOrder.ORIGINAL,
    load_specific_sources=("html",),
    page_retry=retry,
    item_retry=retry,
    page_error_mode=ErrorMode.SKIP,
    item_error_mode=ErrorMode.YIELD,
    page_error_handler=handle_scrape_error,
    item_error_handler=handle_scrape_error,
)

async for result in client.search("college", iterator_config=iterator_config):
    print(result.unwrap().title if result.succeeded else result.error)

Search Videos search()

async
Queries TNAFlix video search and yields results as an asynchronous generator.
async for result in client.search( query: str, sorting_sort: str | Sort = Sort.Sort_relevance, sorting_date: str | SortDate = SortDate.Sort_all, pages: int = 1, iterator_config: IteratorConfig | None = None ) -> AsyncGenerator[ScrapeResult[Video], None]

Parameters

  • query str — Search query term
  • sorting_sort str | Sort — Sort criteria enum (default: Sort.RECENT)
  • sorting_date str | SortDate — Date filtering enum (default: SortDate.ALL_TIME)
  • pages int | str — Number of search pages to parse (default: 2) or "all"
  • iterator_config IteratorConfig | None — Optional v4 iterator policy. Defaults to eagerly loading html source.

Returns

→ AsyncGenerator[ScrapeResult[Video], None]

Behavior and edge cases

Canonical watch links, numeric IDs, short/embed links, relative profile/channel paths and supported plural aliases are normalized. Embedded pages follow their canonical watch link when full metadata is omitted. get_pornstar() returns a Pornstar object. Sort and SortDate are exported by the package; date sorting uses the website’s u parameter.

Use await video.get_author(load_html=False) and async for star in video.get_pornstars(load_html=False). These are callable methods, not properties. Author lookup can return a profile or channel; performer iteration yields Pornstar objects. Channel links are excluded from tags and categories.

🔍 Search & Filtering

Perform advanced video searches on TNAFlix using the client.search() generator combined with sorting criteria:

python
from tnaflix_api import Client
from tnaflix_api.modules.sorting import Sort, SortDate

client = Client()

# Search for top-rated videos from the past month
async for result in client.search(
    query="blonde",
    sorting_sort=Sort.TOP_RATED,
    sorting_date=SortDate.THIS_MONTH,
    pages=3
):
    if result.succeeded:
        video = result.unwrap()
        print(video.title, video.url, video.length)
    else:
        print(f"Error: {result.error}")

⬇️ Downloading Options

TNAFlix serves progressive direct MP4 streams with signed tokens. Downloads are configured via DownloadConfigRAW:

python
from base_api import DownloadConfigRAW

config = DownloadConfigRAW(
    quality="best",            # "best", "half", "worst", or height int (e.g. 720, 1080)
    path="./downloads",        # Destination directory or file path
    no_title=False,            # If False, automatically appends video title + ".mp4"
    allow_multipart=True,      # Enable multi-threaded byte-range chunk downloading
    max_workers=5              # Concurrent download workers
)

success = await video.download(configuration=config)

For more options and configuration details, refer to the eaf_base_api Documentation.

⚠️ Error Handling

Source loaders wrap low-level network errors into typed exceptions from tnaflix_api.modules.errors. Media-loading calls expose errors via base_api.MediaLoadError.

ExceptionTrigger Cause
NotFoundServer returned HTTP 404 (e.g. video or profile removed)
NetworkErrorRequest failed due to connection error, exhausted retries, or HTTP status error
BotDetectionCloudflare or anti-bot challenge block encountered
ProxyErrorProxy configuration error or proxy endpoint unavailable
UnknownNetworkErrorUnrecognized networking exception
DownloadFailedDownload transfer or preparation failed with full cause retained in __cause__
python
from base_api import MediaLoadError
from tnaflix_api.modules.errors import NotFound, BotDetection

try:
    video = await client.get_video(url)
except MediaLoadError as error:
    if isinstance(error.original_error, NotFound):
        print("This video does not exist!")
    elif isinstance(error.original_error, BotDetection):
        print("Scraper was blocked by anti-bot measures.")
    else:
        raise

💻 CLI Usage

TNAFlix API includes a command-line interface accessible via the tnaflix_api binary or python -m tnaflix_api:

bash
tnaflix_api --download "https://www.tnaflix.com/hd-videos/example-video-12345" --quality best --output ./downloads

python -m tnaflix_api --download "https://www.tnaflix.com/hd-videos/example-video-12345" --quality 720 --output ./downloads

tnaflix_api --file urls.txt --quality best --output ./downloads --no-title False

CLI Options

FlagDescription
--download URLVideo URL to download
--file FILEText file containing video URLs (newline-separated)
--quality QUALITYDesired resolution quality (best, half, worst, or height integer)
--output DIRDestination folder or file path
--no-title True/FalseSkip auto-appending video title to output filename (default: False)
