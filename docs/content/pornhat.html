Pornhat API getting started

Version 0.1.0. Distribution: unofficial-api-for-pornhat. Import: pornhat_api. Requires Python 3.12+ and eaf-base-api>=4.2.6, selectolax, and m3u8.

Install from PyPI:

pip install unofficial-api-for-pornhat

FFmpeg is needed for MP4 remuxing and metadata tags; ffprobe is used by the live tests.

import asyncio
from base_api import BaseCore
from base_api.modules.config import RuntimeConfig
from pornhat_api import Client, DownloadConfigHLS

async def main():
    runtime = RuntimeConfig()
    runtime.max_workers_download = 4
    runtime.videos_concurrency = 2
    runtime.pages_concurrency = 2
    async with BaseCore(runtime) as core, Client(core) as client:
        video = await client.get_video("https://www.pornhat.com/video/armani-black-wants-her-husband-s-friend-deep-inside/")
        print(video.title, video.duration, video.views)
        print(await video.get_available_qualities())
        await video.download(DownloadConfigHLS(quality="best", path="./", remux=True))

if __name__ == "__main__":
    asyncio.run(main())

Every runtime request and download uses the shared BaseCore. Client() owns and closes its own core; Client(core) leaves the supplied core open. Use both context managers as above when injecting a core. Retain the client/core until you finish using returned media objects.

The API exposes videos, model profiles, grouped channels, paysite/brand collections, tags, search, new/popular/trending video listings, and sortable model/channel directories. Favorites and history are browser-local. There is no account, playlist or related-player API.

html combines matching JSON-LD and scoped page/player data from one HTML request. media resolves public player redirects and depends on HTML. No separate public metadata API was found; no api source or load_api argument is exposed.

See Client, Video, source loading, downloads, and shared configuration.

Client — Pornhat API

Client(core: BaseCore | None = None, *, base_url: str = "https://www.pornhat.com") creates typed objects sharing one configured backend. base_url must be a verified origin, with no resource path; it controls search, catalog, tag directory and profile-directory requests. Individual getters retain the host in their supplied URL.

Use async with Client() as client or await client.close(). Only an internally created core is closed. An injected core remains caller-owned.

async def get_video(url: str, *, load_html: bool=True, load_media: bool=False) -> Video: ...

Return Video. HTML loads by default. load_html=False creates a deferred object; load_media=True resolves media (loading HTML first even if load_html=False). Requires an absolute /video/<slug>/ URL.

Return a grouped Channel from an absolute /sites/<slug>/ URL. This is distinct from the paysite/brand collection.

Return model-directory ScrapeResult[Model] objects. Supports ProfileSort.RANK, VIDEOS, UPDATED and ABC. Alphabet letter accepts A–Z or None for All. The model directory has no other group.

Return channel-directory ScrapeResult[Channel] objects. Uses the same sorting enum as models, with the additional alphabet group letter="other".

get_categories

async def get_categories(*, load_html: bool=False) -> list[Category]: ...

Await a list of all tag Category objects. These are deferred by default (load_html=False), with only URL/core identity loaded. load_html=True loads each category sequentially and can issue many requests; prefer loading selected categories.

Listing options

pages is a positive count or "all". start_page is a positive, one-based index. The first listing page is fetched lazily at iteration time to discover pagination for every range. The requested range is clamped to the live last page. Beyond-last ranges yield nothing; invalid page options raise ValueError. pages="all" follows all remaining numbered pages.

Listings return ScrapeResult values: call result.unwrap() to surface failures. Defaults load html for each result, preserve original page/card order, and yield terminal page/item failures. An explicitly supplied IteratorConfig is honored. Initial pagination-discovery failures propagate directly. See iteration.

See hosts and sorting.

Load author_link if necessary and return the related Channel, or None when absent.

download

async def download(configuration: DownloadConfigHLS, *, refresh: bool=False): ...

Load title and media, copy the download configuration, and delegate to core.download. Returns bool or shared DownloadReport according to return_report. refresh=True invalidates cached page data and loads fresh sources on a separate object, leaving the original metadata state intact.

Relationship getters are awaited methods and support load_html=False for deferred related objects. They share the parent core; keep that core open. Example:

async def inspect_relationships(video):
    channel = await video.get_channel(load_html=False)
    models = await video.get_models()
    site = await video.get_site(load_html=False)
    return channel, models, site

videos / get_videos

def videos(*, pages: int | Literal['all']=1, start_page: int=1, iterator_config: IteratorConfig | None=None) -> ScrapeStream[Video]: ...

get_videos is an alias of videos with the same arguments and return type. Results are ScrapeResult[Video] values, sharing this collection's core. Default iteration loads each video's HTML. Pass an IteratorConfig to select fields/sources, concurrency, ordering and error handling. pages is a positive count or "all", and start_page is one based.

from base_api import make_iterator_config

async def list_collection(client):
    collection = await client.get_model("https://www.pornhat.com/models/armani-black/")
    config = make_iterator_config(load_specific_sources=())
    async with collection.videos(pages="all", iterator_config=config) as results:
        async for result in results:
            video = result.unwrap()
            print(video.video_id, video.url)

Iteration uses the collection's intended listing region, excluding navigation, ads and other page regions. There are 59 real cards on observed full profile pages; the library follows actual numbered pagination rather than calculating offsets from an assumed capacity. Beyond-last ranges return an empty stream. Known zero-video channels remain valid profiles. The library does not apply global deduplication across rendered pages.

Source loading — Pornhat API

Pornhat exposes html metadata and media redirect resolution. Embedded JSON-LD and data-setup JSON belong to the HTML request, not an independent public JSON API. Collections only declare html. Videos declare both sources.

Request Behavior
await client.get_video(url) Load HTML metadata only
await client.get_video(url, load_html=False) Construct without requests
await client.get_video(url, load_html=False, load_media=True) Media loader first ensures HTML, then resolves sources
await video.load_sources("html", "media") Load both, respecting the media dependency
await video.load_fields("title") Load HTML if needed
await video.load_fields("m3u8_base_url") Load HTML plus media if needed
video.to_dict() Serialize loaded fields without requests 
async def inspect_lazily(client, url):
    video = await client.get_video(url, load_html=False)
    assert not video.loaded_sources
    snapshot = video.to_dict()
    await video.load_fields("title", "duration")
    assert video.loaded_sources == {"html"}
    await video.load_sources("media")
    assert video.loaded_sources == {"html", "media"}
    return snapshot, video.to_dict()

Field access is synchronous and cannot fetch: unresolved fields raise DataNotLoadedError. Known missing fields are None, while relationships can be empty lists. Inspect is_field_loaded(name), unloaded_fields(), loaded_sources, source_state(source) and source_errors before consuming partial objects. to_dict(include_unloaded=True) represents unloaded fields as None; use the default to preserve loaded-versus-unloaded distinction.

Listings can construct Video objects with URL and stable video_id already present, without claiming their HTML source is loaded. Default listing configuration then loads HTML; make_iterator_config(load_specific_sources=()) keeps those objects deferred.

HTML data is committed atomically by the shared model. It is never overwritten by lower information media resolution; each loader owns separate fields. Failed loaders raise shared MediaLoadError or MediaLoadErrors with original causes and leave source errors inspectable.

See Video, errors, and shared media models.

Searching and filtering — Pornhat API

Client.search(query, *, pages=1, start_page=1, iterator_config=None) returns a lazy video stream. Whitespace becomes hyphens before percent encoding, matching the site's form. Do not manually construct %20 search routes: the observed site rejects those paths. Only a nonblank query and page/iterator options are accepted; there are no search sort, upload date, duration, quality, country, gender or language filter arguments. Select a verified locale origin with Client(base_url="https://de.pornhat.com").

from base_api import make_iterator_config
from pornhat_api.modules.sorting import ProfileSort, Sort

async def browse(client):
    lazy = make_iterator_config(load_specific_sources=())
    async with client.search("Armani Black", pages=2, iterator_config=lazy) as results:
        async for result in results:
            print(result.unwrap().video_id)
    async with client.get_videos(sort=Sort.TRENDING, iterator_config=lazy) as results:
        first = (await anext(results)).unwrap()
        print(first.url)
    async with client.get_models(sort=ProfileSort.ABC, letter="A", iterator_config=lazy) as results:
        first_model = (await anext(results)).unwrap()
        print(first_model.url)

Profile directory sorting supports rank, video count, updated and alphabet groups. Models accept A–Z or All; channels also accept other. The sorting reference contains exact enum members and values.

Iteration and results — Pornhat API

Video catalogs, search, model/channel directories, and collection .videos() return ScrapeStream objects. Construction is lazy; iteration fetches the first listing page to inspect actual pagination, then requests the bounded selected range through the shared helper.

Option Meaning
pages=1 One page (default)
pages=N Positive count of pages from start_page, clamped to the last page
pages="all" All remaining pages
start_page=1 Positive one-based first requested page
iterator_config=None HTML-loaded items, original ordering, yielded terminal item/page errors

Beyond-last ranges return an empty stream. Invalid counts, booleans or nonpositive indices raise ValueError. Initial navigation-discovery errors propagate directly; later page/item failures follow IteratorConfig. Call result.unwrap() so failures are not silently ignored.

from base_api import make_iterator_config

async def list_all(client):
    model = await client.get_model("https://www.pornhat.com/models/armani-black/")
    config = make_iterator_config(
        load_specific_sources=(),
        order="original",
        page_error_mode="raise",
        item_error_mode="raise",
        max_page_concurrency=2,
        max_item_concurrency=2,
    )
    async with model.videos(pages="all", iterator_config=config) as results:
        async for result in results:
            video = result.unwrap()
            print(video.video_id, video.url)

Without a caller configuration, the provider requests html for each item. To request only certain fields, use make_iterator_config(load_specific_sources=(), load_specific_fields=("title",)). Because all video metadata shares one HTML loader, requesting title also loads that page's other HTML fields. Requesting media fields additionally resolves player redirects. An explicit IteratorConfig is honored without replacing its source/error/order settings. order="completion" permits completion order; the default is original page/card order.

Use async with or await stream.aclose() when stopping early so pending work is closed. Do not close the injected core until all streams and returned object operations finish.

Downloading — Pornhat API

The verified player endpoints look like MP4 URLs but redirect to real HLS masters. Use DownloadConfigHLS; the provider exposes no direct-MP4 downloader. Preserve signed query strings and use Video.download rather than guessing CDN routes.

from pornhat_api import DownloadConfigHLS

async def download_video(video):
    qualities = await video.get_available_qualities()
    config = DownloadConfigHLS(
        quality="best",
        path="./downloads/",
        remux=True,
        return_report=True,
        metadata={"title": video.title, "artist": video.author_name},
        callback=lambda current, total: print(current, total),
    )
    report = await video.download(config, refresh=True)
    assert report.status == "completed" and not report.missing
    return qualities, report

Create the output directory first. Without no_title=True, the shared provider helper joins the configured directory with the sanitized video title and .mp4 extension. For an exact output filename, set path="./video.mp4", no_title=True. Configurations are copied before the path/master is assigned. Callbacks, stop events, metadata and caller options are preserved; the caller's path and master setting are unchanged. Inspect the returned report for metadata success instead of relying on mutation of the original configuration's metadata_written field.

Quality selection

An explicit unavailable tier uses the shared nearest available resolution, preferring the higher tier on a tie. The master determines available qualities; no resolution is invented from labels, marketing flags, or URL suffixes. Additional quality sets were not observed.

Refresh, reports and cancellation

refresh=True invalidates the page cache and resolves fresh sources on a new Video sharing the same core and stable ID. It does not overwrite the original object's loaded fields. This refreshes normally accessible expiring URLs without altering signatures.

Downloads delegate to core.download. return_report=True returns the shared DownloadReport with status, total, downloaded, missing, and metadata_written; otherwise the backend returns a boolean or raises. A returned failed/cancelled report must be inspected and is not a successful transfer. Shared stop_event, segment resume options, progress callbacks and metadata handling are passed through. remux=True needs FFmpeg; optional metadata and thumbnail inputs follow shared download configuration contracts.

Errors and troubleshooting — Pornhat API

Provider exception imports in pornhat_api.modules.errors re-export shared BotDetection, DownloadFailed, NetworkError, NotFound, ProxyError, UnknownNetworkError and VideoUnavailable. BaseMedia loading wraps ordinary loader failures in MediaLoadError, or MediaLoadErrors for multiple sources. Inspect the original cause; catching only the inner provider error around get_video() will miss the loading wrapper.

from base_api import MediaLoadError, MediaLoadErrors, is_resource_gone

async def fetch_video(client, url):
    try:
        return await client.get_video(url)
    except (MediaLoadError, MediaLoadErrors) as error:
        if is_resource_gone(error):
            print("Resource no longer available:", url)
        raise
Symptom Meaning / action
ValueError on URL construction Use an absolute URL on a verified host and the correct resource route; arbitrary mirrors and directory URLs are rejected.
ValueError for pages/letter/sort Positive integer page options or pages="all" are required; letters require ABC; models have no other group.
