Porn.com API getting started

Version 0.1.0. Distribution: unofficial-api-for-porn. Import: porn_api. Requires Python 3.12+, eaf-base-api[hls]>=4.2.6, and selectolax.

Install from PyPI:

pip install unofficial-api-for-porn

FFmpeg is required when requesting MP4 remuxing or export metadata; ffprobe is used by the live download checks. No account or browser cookies are required for the verified public scenes.

import asyncio
from contextlib import aclosing
from base_api import BaseCore
from base_api.modules.config import RuntimeConfig
from porn_api import Client, DownloadConfigHLS

async def main():
    runtime = RuntimeConfig()
    runtime.request_delay = 1
    runtime.videos_concurrency = 2
    async with BaseCore(runtime) as core, Client(core) as client:
        video = await client.get_video("https://www.porn.com/scene/208974141")
        print(video.title, video.duration)
        print([(r.width, r.height) for r in await video.get_qualities()])
        await video.download(DownloadConfigHLS(
            quality="worst", path="./", remux=True, return_report=True,
        ))
        async with aclosing(client.search("yoga", pages=1)) as stream:
            async for result in stream:
                summary = result.unwrap()
                print(summary.video_id, summary.title)

if __name__ == "__main__":
    asyncio.run(main())

Client() owns its default core and closes it through its async context manager or await client.close(). An injected core remains owned by the caller. Every request and download uses that same backend; response caches, retries, proxy, locale, timeouts, and cancellation remain configurable per core.

Porn.com includes native HLS scenes and external referrals. Both have usable scene metadata; only native public unencrypted HLS is downloadable here. Check video.is_playable after loading scene HTML. Referral summaries do not mean that media is available on Porn.com.

See Client, source loading, downloads, and supported hosts.

Client — Porn.com API

Client(core: BaseCore | None = None, *,
       base_url: str = "https://www.porn.com",
       orientation: Literal["straight", "gay", "trans"] = "straight")

Supports async with Client() as client and await client.close(). Only an internally created BaseCore is closed by the client. base_url is a verified host URL without a resource path or query. Orientation prefixes apply to search and directory methods, not to the URLs passed to individual getters.

Method Result Behavior
await get_video(url, load_html=True) Video Valid /scene/<numeric-id>[/<slug>] URL; eager HTML by default.
await get_pornstar(url, load_html=True) Pornstar A real single-pornstar profile page.
await get_channel(url, load_html=True) Channel A real single-channel studio profile.
await get_category(url, load_html=True) Category Category page or /gay//trans directory root.
await get_source(url, load_html=True) Source A source-website index such as /xnxx.
search(query, *, pages=1, start_page=1, filters=None, iterator_config=None) Async ScrapeResult[Video] stream Encoded sq search; preserves legitimate redirects to a category.
pornstars(*, pages=1, start_page=1, iterator_config=None) Async ScrapeResult[Pornstar] stream /pornstars directory.
channels(*, pages=1, start_page=1, iterator_config=None) Async ScrapeResult[Channel] stream /sites directory.
categories(*, iterator_config=None) Async ScrapeResult[Category] stream A–Z /categories directory; no page-count argument.

Getters take absolute URLs on accepted hosts; relative URLs and outbound /out/... links are not accepted by get_video. Constructors validate URL identity; HTML loading checks the actual scene ID or profile type before committing fields. A channel URL does not become a valid performer object just because it contains videos.

Individual load_html=False constructs a deferred object. Listing methods return directly observed summaries without loading every detail page. Use result.unwrap() before reading an item. pages accepts a positive integer or "all"; start_page is one-based. filters is a Filters object.

There are no get_videos, get_categories, get_channels, or get_pornstars aliases: directory method names are exactly categories, channels, and pornstars. No account, playlist, independent Model/User, or JSON video API is implemented.

See iteration and Video.

Video — Porn.com API

Video(url=..., core=...) is a keyword-only BaseMedia dataclass. Prefer await client.get_video(url) for eager HTML metadata, or pass load_html=False for deferred loading. The stable URL ID must match the response scene identity.

HTML-backed fields use media_field("html"). Unresolved fields raise DataNotLoadedError; None means known absence after loading. Listing summaries seed only observed fields and retain listing-only rating/preview/source/link data when scene HTML is loaded. Direct scene getters do not fetch a listing to invent these optional observations.

The scene document's JSON-LD, canonical link, Open Graph title, dates, and image refer to the generic WordPress /scene page. They are excluded. There is no fabricated video description, view count, upload date, or vote count.

Renditions

await video.get_qualities() loads required HTML and the actual HLS master. It returns a list of immutable Rendition objects, sorted by height then bandwidth:

Field Type Meaning
width int Actual master-playlist width.
height int Actual master-playlist height.
bandwidth int | None Declared rendition bandwidth.
url str Resolved variant URL, including required signature context.

No persistent video_qualities, renditions, direct MP4 source mapping, or separate media loader exists. Inspect get_qualities() when media information is needed. A referral without a master raises VideoUnavailable.

Relationships

channel = await video.get_author(load_html=True)
performers = await video.get_pornstars(load_html=True)
source = await video.get_source(load_html=True)
async for result in video.related_videos(iterator_config=None):
    related = result.unwrap()

These are methods, not async properties. get_author() returns Channel | None; get_pornstars() returns a list of linked Pornstar objects. get_source() returns Source | None when the originating listing supplies a source URL. Unlinked performer names are not guessed into URLs. All objects share the core. related_videos() is a one-page result stream of the scene's related grid.

Download

await video.download(configuration: DownloadConfigHLS, *, refresh: bool = True)

Delegates to BaseCore.download after checking public unencrypted HLS variants. Returns the shared boolean or DownloadReport according to configuration. Caller configuration is copied; a fresh signed scene source is fetched by default. See downloading.

Collection — Porn.com API

Collection is the keyword-only BaseMedia base for Pornstar, Channel, Category, and Source. Use the corresponding Client getter to validate the actual domain type. Its only metadata source is html.

Field Type Meaning
url str Actual profile/category/source URL on a verified host.
core BaseCore Shared caller-configured backend.
resolved_url str | None Actual response URL where recorded.
name str | None Target page heading.
description str | None Plain-text biography/description where exposed.
language str | None Response HTML locale.
video_count int | None Advertised total, including positions replaced by native ads where observed.
profile_id str | None Body data-pi entity ID, with zero/missing values represented as None.
info dict[str, str] | None Native localized labels and text values for profile details/statistics.
social_links list[str] | None Observed links in profile information, including an official site where supplied.

                  start_page: int = 1, filters: Filters | None = None,
                  iterator_config: IteratorConfig | None = None)

Returns an async stream of ScrapeResult[Video], initially containing listing summaries. pages counts requested pages from the one-based start_page; "all" follows the complete exposed feed. URL filters survive pagination unless the caller supplies a replacement Filters object. Ads are excluded; real duplicate/pinned entries and entries blended into the grid retain their order.

video_count is the website's advertised count, not len(unique_ids). The initial implementation reconciled total grid positions exactly after native ad replacements were accounted for. It does not fabricate results to match a counter. See live validation.

Native profile info retains localized labels rather than silently converting them into another provider's schema. A verified German heading renders malformed ge Videos; its valid Gesamtzahl der Videos statistic is used as a fallback. Generated biography prose is not used to infer the video count.

See iteration, filters, and source loading.

Pornstar — Porn.com API

Pornstar(Collection) represents a real performer page whose HTML body declares single-pornstar. Its lazy fields and .videos(...) signature are documented under Collection. There is no separate Model class.

from contextlib import aclosing
from porn_api import Client

async def inspect_performer():
    async with Client() as client:
        star = await client.get_pornstar("https://www.porn.com/azumi-mizushima")
        print(star.name, star.video_count, star.info)
        async with aclosing(star.videos(pages="all")) as stream:
            async for result in stream:
                print(result.unwrap().video_id)

English examples expose gender, birthday, birthplace, ethnicity, height, hair and eye color, rank, total videos, and video views in info where supplied. Values remain the site's strings. Missing profile fields are not guessed from other pages or from a performer's name.

client.pornstars(...) enumerates the performer directory as typed result summaries. await video.get_pornstars() resolves only actual scene links. The verified one-video profile returns ID 205464990; the larger Mia Khalifa profile requires continuing numeric pages beyond its disabled Next link. See profile reconciliation.

Channel — Porn.com API

Channel(Collection) represents a studio/channel page with HTML body type single-channel. A source website such as XNXX is a distinct Source. Use actual links instead of deriving channel URLs from a video title.

from contextlib import aclosing
from porn_api import Client

async def inspect_channel():
    async with Client() as client:
        channel = await client.get_channel("https://www.porn.com/bratty-sis")
        print(channel.name, channel.description, channel.info)
        async with aclosing(channel.videos(pages="all")) as stream:
            async for result in stream:
                video = result.unwrap()
                print(video.video_id, video.title, video.source_name)

All fields and .videos(...) arguments come from Collection. An official-site link, rank, advertised total, and video views remain in native info/social_links where supplied. client.channels(...) enumerates /sites as ScrapeResult[Channel] summaries; it is not an awaited list.

The initial complete comparisons matched four visible Bratty Sis video entries plus two native ads, and 1,618 Brazzers entries plus 42 ads. Brazzers has one repeated ID on separate pages; iteration preserves both live occurrences. See live validation.

Category — Porn.com API

Category(Collection) represents an actual single-category page, such as https://www.porn.com/yoga-porn. await client.get_category(url) loads metadata by default; client.categories() streams summaries from the A–Z directory. The full field table and video signature are in Collection.

from contextlib import aclosing
from porn_api import Client, Filters

async def browse_category():
    async with Client() as client:
        category = await client.get_category("https://www.porn.com/yoga-porn")
        async with aclosing(category.videos(
            pages=1, filters=Filters(source="xVideos", min_minutes=20),

            async for result in stream:
                print(result.unwrap().title)

Orientation directory roots

The straight category directory can link /gay and /trans. These are category directory roots, not direct video grids. category.is_directory identifies them; .videos(...) raises ValueError with instructions to browse categories.

async def browse_orientation(client):
    root = await client.get_category("https://www.porn.com/gay")
    if root.is_directory:
        async for result in root.categories():
            print(result.unwrap().url)

Category.categories(*, iterator_config=None) is only supported on these two roots. Client(orientation="gay") or "trans" selects the corresponding directory/search prefix. Individual category URLs such as /gay/twink-porn and /trans/tgirl-porn are accepted. No guessed category ID or image is derived from a related video thumbnail.

Source — Porn.com API

Source(Collection) represents the site-wide index for a source website, for example https://www.porn.com/xnxx. It validates HTML body type single-source. It is distinct from a studio Channel.

from contextlib import aclosing
from porn_api import Client

async def browse_source():
    async with Client() as client:
        source = await client.get_source("https://www.porn.com/xnxx")
        print(source.name, source.video_count)
        async with aclosing(source.videos(pages=1)) as stream:
            async for result in stream:
                summary = result.unwrap()
                print(summary.video_id, summary.source_name)

The inherited metadata and .videos(...) contract are in Collection. An originating listing card can supply Video.source_name, source_url, and its original link_url. await summary.get_source(load_html=True) resolves the actual source URL, or returns None when there is no such observation. Direct scene fetching does not automatically infer source metadata from the title.

Fetching this collection or a referral's metadata does not fetch its external website. Large source indexes are validated on representative pages; the initial validation did not enumerate their entire multi-million-entry catalogs.

Filters — Porn.com API

Filters is a frozen, slotted dataclass exported by porn_api:

Filters(added_days: Literal[1, 7, 30, 90, 365] | None = None,
        source: str | None = None, hd: bool = False,
        min_minutes: int | None = None, max_minutes: int | None = None)
Field Website parameter Meaning
added_days ad Today, week, month, three months, or year; None leaves the period unrestricted.
source so Actual source label such as xVideos or XNXX.
hd qu=hd Request the site's HD filter.
min_minutes ll Nonnegative integer minimum, in minutes.
max_minutes lh Nonnegative integer maximum, in minutes.

filters.apply(url) returns the URL with these named filter parameters replaced; None/false settings remove their corresponding keys. Other query keys are preserved. Supplying a Filters object therefore replaces existing values for these filter keys; omitting it preserves an existing URL's filters.

Unsupported added periods, negative/non-integer duration bounds, or an inverted minimum/maximum raise ValueError. The implementation performs duration validation when apply() is called. There is no separate sorting enum or sort parameter. Listing filter behavior follows the website, including injected cards that can fall outside a requested filter.

See searching.

CLI — Porn.com API

Both porn_api and python -m porn_api invoke the same entry point. The scene URL is a required positional argument; --download is a boolean flag, not the argument that takes the URL.

porn_api -h
porn_api https://www.porn.com/scene/208974141
python -m porn_api https://www.porn.com/scene/208974141 --download --quality worst --output ./
Option Default Meaning
url Required positional value Verified Porn.com /scene/<id>[/<slug>] URL.
--download False Download public HLS; otherwise print loaded metadata as JSON.
--output ./ Output directory; a title-derived MP4 filename is applied.
--quality best best, half, worst, or a positive resolution height/numeric string.
-h, --help — Show parser help.

CLI downloads create DownloadConfigHLS(..., remux=True) and therefore require FFmpeg. JSON inspection can contain expiring signed media URLs. The Client's async context manager closes its core after inspection/download.

There are no --file, --no-title, or direct MP4 format flags in this provider. Use the Python download interface for callbacks, reports, exact output paths, metadata export, or cancellation settings.

Source loading — Porn.com API

Video and the Collection subclasses declare one source: html. Individual Client getters load it by default. No independently selectable public video API was established: the REST root returned 401, while embedded WordPress schema describes the generic /scene page. There are no load_api flags or media loader. get_qualities() explicitly requests the real HLS master when needed.

from porn_api import Client

async def inspect_sources():
    async with Client() as client:
        video = await client.get_video(
            "https://www.porn.com/scene/208974141", load_html=False,
        )
        print(video.loaded_sources, video.to_dict())
        await video.load_fields("title", "duration")
        print(video.title, video.duration)
        await video.load_sources("html")
        print(video.to_dict())

The shared BaseMedia loader applies field mappings atomically. Attribute access is synchronous and never starts network I/O. An unloaded field raises DataNotLoadedError; a loaded None or empty relationship list represents known absence. Repeated/concurrent source loads share the shared media contract.

Use loaded_sources, source_state("html"), source_errors, is_field_loaded(name), unloaded_fields(), load_fields(...), and load_sources(...) to inspect or load state. to_dict() omits unresolved fields and the core by default; include_unloaded=True/include_core=True are explicit serialization options and do not fetch extra sources.

Listings return summary objects with observed title/poster/duration/rating or directory name already seeded. Other scene/profile fields remain unresolved. Because a summary already has title, load_fields("title") may perform no detail request. Call load_sources("html") to request full scene metadata, or set IteratorConfig(load_specific_sources=("html",)) for eager item loading. When referral HTML lacks a poster or exact duration, its observed listing image and rounded length label are retained. Listing provenance remains separate.

Unsupported source names raise shared loader configuration errors. See errors and iteration.

Searching and filtering — Porn.com API

Client.search(query, *, pages=1, start_page=1, filters=None, iterator_config=None) streams ScrapeResult[Video]. A query must contain 1–100 characters and not be whitespace-only. The client encodes it under sq. Search can legitimately redirect to a category: yoga resolves to /yoga-porn. An unmatched search uses a verified empty-results layout, not a fake empty Video.

from contextlib import aclosing
from porn_api import Client, Filters

async def search_videos():
    async with Client() as client:
        filters = Filters(source="xVideos", min_minutes=20, hd=True)
        async with aclosing(client.search("yoga", pages=2, filters=filters)) as stream:
            async for result in stream:
                summary = result.unwrap()
                print(summary.video_id, summary.title)

The same Filters object works with Pornstar.videos, Channel.videos, Category.videos, and Source.videos. For an existing resource URL, omitting filters preserves its query filters; passing a Filters object replaces the supported filter keys.

Select a verified language host with Client(base_url="https://de.porn.com"). Use Client(orientation="gay") or "trans" for /gay/search or /trans/search and the corresponding directories. Individual getters retain the URL supplied by the caller rather than automatically adding an orientation prefix.

The backend reproduces the live response grid. Some injected cards can fall outside a duration/source/quality filter, and displayed totals can remain unfiltered. In the initial live run, yoga's added_days=1 and 7 returned an explicit page-0 empty listing; the other tested filters returned actual cards. No additional sort parameter or sorting enums were verified.

See pagination and result handling.

Iteration and results — Porn.com API

Search, profile/category/source videos, related videos, and directories return async ScrapeResult streams. Defaults construct observed summaries and raise terminal errors. Every result must be unwrapped; a configured yielded failure must not silently disappear from the caller's loop.

from contextlib import aclosing
from base_api import ErrorMode, IteratorConfig, ResultOrder
from porn_api import Client

async def iterate_profile():
    config = IteratorConfig(
        order=ResultOrder.ORIGINAL,
        max_item_concurrency=2,
        page_error_mode=ErrorMode.RAISE,
        item_error_mode=ErrorMode.RAISE,
        load_specific_sources=(),
    )
    async with Client() as client:
        channel = await client.get_channel("https://www.porn.com/bratty-sis")
        async with aclosing(channel.videos(pages="all", iterator_config=config)) as stream:
            async for result in stream:
                video = result.unwrap()
                print(result.page_index, result.item_index, video.video_id)

IteratorConfig also controls item/source/field loading, error handling, retries, and completion ordering. Set load_specific_sources=("html",) for full item loading, or load_specific_fields=("duration",) to request a required lazy field. An already seeded field need not trigger a detail fetch. The exact caller configuration is passed through to the shared Helper for each page.

Pagination

  • start_page is a positive one-based page number; pages is a positive count from that start or the string "all".
  • Real Next links determine the next URL. Paging is sequential; item work on a page remains bounded/configurable. This wrapper does not concurrently prefetch a guessed range of pages.
  • Disabled/missing Next links are not sufficient proof of completion. If more pages were requested, the established pg route is probed until a genuine empty page or terminal boundary 404. Repeated URLs/entire pages raise errors.
  • A boundary probe's 404 ends iteration. An explicitly requested initial page returning 404 raises a typed page error. Other failures remain governed by the caller's error policy. A skipped/failed page cannot establish completeness.

The verified Mia Khalifa grid disables Next at page 13, but pages 14–23 still contain videos. Page 24 returns 404. pages="all" includes these extra live pages. No hard-coded page size or advertised count truncates the feed.

Only actual cards in the intended video grid become items; native ad slots have no video identity and are excluded. Duplicate/pinned IDs and recommendations blended into that grid are preserved in site order. video_count is an advertised slot total, not a unique-ID count. Reconciliation records the observed differences exactly. Use aclosing when stopping a stream early.

Downloading — Porn.com API

Native public scenes expose HLS masters. await video.get_qualities() inspects their actual width/height/bandwidth and preserves signed variant URLs. A referral without native media raises VideoUnavailable; this wrapper does not follow its outbound link to implement another site's downloader.

from porn_api import Client, DownloadConfigHLS

async def download_video():
    async with Client() as client:
        video = await client.get_video("https://www.porn.com/scene/208974141")
        config = DownloadConfigHLS(
            quality="worst", path="./", remux=True, return_report=True,
            metadata={"title": video.title},
        )
        report = await video.download(config)
        print(report.status, report.downloaded, report.total, report.metadata_written)

Video.download(configuration, *, refresh=True) requires DownloadConfigHLS and delegates to BaseCore.download. No direct full-video MP4 source or RAW download mode was verified. remux=True converts the completed HLS MPEG-TS output to MP4 with FFmpeg. With remux=False, the file contains MPEG-TS regardless of a .mp4 extension. no_title=True treats path as the exact output file path; otherwise a sanitized title-derived filename is appended to the output directory.

Quality selection

Selector Behavior
best Highest actual available height.
half Middle available height, not half the best resolution numerically.
worst Lowest actual available height.
Positive integer / numeric string such as 720 or "720p" Exact height if available; otherwise nearest tier, preferring the higher on a tie.

Recorded sample sets are 360p/480p/1080p (208974141) and 360p/480p/720p (208581087). Requesting 720 on the first set selects 480. Marketing HD labels are not used to invent unavailable renditions.

Configuration and source lifetime

Signed URLs can expire or vary after session cookies are established. Each download refreshes the scene through the shared cache refresh policy by default, using a new model so concurrent operations do not mutate the existing Video. refresh=False reuses its current metadata. Caller configuration is copied; callbacks and cancellation signals remain attached to the operation. Shared request headers are not mutated per video.

Use shared DownloadConfigHLS fields for callback, callback_remux, stop_event, metadata, thumbnail, return_report, remuxing, and supported resume settings. Progress/report semantics remain those of the shared backend. Native encrypted/protected variant playlists are rejected before downloading; there is no authorization or DRM bypass.

All renditions in both sample sets were completely downloaded and checked with ffprobe. Additional complete files covered metadata export, callbacks, reports, presets/fallback, refreshed repeats, TS output, concurrent videos, and the CLI. See live validation for the measured evidence.

Errors and troubleshooting — Porn.com API

Provider error imports are available through porn_api.errors:

Exception Meaning
ParseError Unrecognized/mismatched target layout, unexpected redirect, missing listing region, or repeated pagination.
NotFound Missing resource translated by the shared request helper.
NetworkError Shared request/network failure translated by the helper.
BotDetection Bot-protection failure detected by the shared backend.
ProxyError Proxy/SSL configuration failure translated by the helper.
UnknownNetworkError Shared unknown transport error.
VideoUnavailable No native public HLS source, an external referral, or protected media.
DownloadFailed Download failure wrapped with resource/API context.
ScraperException Shared provider exception base.

Errors inside a lazy metadata loader are normally wrapped in shared MediaLoadError; several source failures can use MediaLoadErrors. Inspect original_error/the exception cause instead of expecting a bare provider error from every Client getter. Video.download preserves VideoUnavailable and shared cancellation while wrapping other download errors with DownloadFailed.

Shared DataNotLoadedError means a declared lazy field has not been loaded. Load the html source or the required fields. Unsupported sources such as api or media raise loader configuration errors. They are not substitutes for an actual network source on this site.

Listing failures use PageFetchError, ItemFetchError, or configured yielded ScrapeResult.error values. Always unwrap yielded results. A speculative terminal 404 after a confirmed listing page ends iteration; an initial explicit missing page still raises. Other errors are not converted into successful empty videos.

Symptom Check
ValueError on a URL Supply an absolute verified host and real /scene/<numeric-id>[/<slug>] route, not /out/... or a guessed mirror.
Referral is not downloadable Load HTML and inspect is_playable/unavailable_reason; metadata does not imply Porn.com hosts the stream.
HTML says the wrong profile type Use the corresponding real Pornstar/Channel/Source/Category getter.
Old HLS source fails Keep normal refresh=True download behavior; signatures expire and can vary by session.
No exact requested resolution Inspect get_qualities(); nearest-tier fallback is intentional.
MPEG-TS data in a .mp4 filename Enable remux=True with FFmpeg for an MP4 container.
Counts differ from yielded unique IDs Account for native ad replacements and visible duplicate occurrences before assuming missing videos.
Next is disabled despite more entries Use pages="all"; this provider probes the established numeric route to its real end.

The REST metadata root (401), /pics (403), encrypted/protected streams, and authenticated-only features are outside this integration. Do not treat access denial as a valid empty model. See source loading and iteration.

Supported platforms — Porn.com API

The package requires Python 3.12+. Initial live validation used Linux with CPython 3.15.2, eaf-base-api 4.2.6, FFmpeg, and ffprobe. Other platforms or Python versions have not been validated for this provider.

Straight routes and /gay//trans category/search/directory prefixes are implemented. Orientation root entries are category directories, not video grids. Sampled gay/trans grids had external referrals rather than native HLS.

Boundaries

Only legitimately public native unencrypted HLS is downloaded. External source websites are represented as source indexes/referrals, not crawled for media. No account, playlist, separate Model/User type, full-video direct MP4, or independent JSON video API was verified. The REST root returned 401 and /pics returned 403. These inaccessible capabilities are not advertised as working. Unobserved layouts and future site changes remain unverified.
