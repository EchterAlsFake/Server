{{ name }} walkthrough

Download {{ provider_name }} videos on {{ name }}

{% if platform == 'ios' %}

iPhone setup requires a PC for sideloading. Use iOS 15 or later. Install the IPA with your own Apple account and a compatible sideloading tool; renew signing when required. No jailbreak is needed for the native app.

{% else %}

Use Android 9 or later and an APK compatible with your phone. Installation happens directly on Android.

{% endif %} {{ name }} packages & installation instructions →
  1. 01

    Install and open the app

    {% if platform == 'ios' %}

    On your PC, follow the iPhone installation guide to sign and sideload the IPA. Open Porn Fetch on your iPhone and go to Downloads. Tap Add videos.

    {% else %}

    Get the Android APK, open it, and allow installation from your browser or file manager if Android asks. Open Porn Fetch, go to Downloads, and tap Add videos.

    {% endif %}
    {{ phone_image(platform, 'start', 'Porn Fetch ' ~ name ~ ' Downloads screen with Add videos', '1 · Open Downloads and tap Add videos.') }}
  2. 02

    Paste the video-page link

    In your browser, copy the complete page address of a {{ provider_name }} video you are authorized to save. In Add videos, select Video URL, paste the address, and tap Get Video.

    This fetches the video’s details; it does not start downloading. For a supported profile or playlist, use its corresponding URL type. Check {{ provider_name }}’s supported links below.

    {{ phone_image(platform, 'add', name ~ ' Add videos panel with Video URL, Get Video and Output folder', '2 · Paste your link and tap Get Video. The screenshot uses a PornHub example.') }}
  3. 03

    Choose quality and a destination

    Close the add-video panel if it is still open. Expand the returned video card with its arrow to review the available qualities. Free use supports available streams up to 720p; higher qualities require Premium and a usable source stream.

    {% if platform == 'ios' %}

    Check Output folder in Add videos before starting. “App storage” means the app’s own storage. Use Choose folder if you want another destination.

    {% else %}

    In Add videos, check Output folder and use Choose folder to select a destination you can find in your file manager.

    {% endif %}
    {{ phone_image(platform, 'ready', name ~ ' fetched video card showing Ready, 720 and Download', '3 · A fetched video is ready at 720p. This is a PornHub example, not a completed download.') }}
  4. 04

    Download and find your file

    Tap Download on the video card. Wait for the download to finish; a percentage below 100% means it is still running. Files are saved to your selected folder automatically.

    {% if platform == 'ios' %}

    For app storage, open the iPhone’s Files app and look under Browse → On My iPhone → Porn Fetch, including its PornFetch subfolder. If you chose another folder, look there instead. A download is not automatically added to Photos.

    {% else %}

    Open your phone’s file manager and navigate to the folder you selected. There is no separate per-video Save action.

    {% endif %}
    {{ phone_image(platform, 'downloading', name ~ ' download in progress with a percentage bar and Stop control', '4 · Download in progress. Wait for completion before opening the saved file.') }}
